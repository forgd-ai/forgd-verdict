forgd-verdict {{ .Chart.AppVersion }} installed as {{ .Release.Name }}.

{{ if .Values.ingress.enabled -}}
Configure Anthropic against:

  inference hook   https://{{ .Values.ingress.host }}/hook
  OTLP endpoint    https://{{ .Values.ingress.host }}

The OTLP value is the BASE url, with no path. An OTLP exporter appends
/v1/logs or /v1/traces itself depending on the signal, so pasting either of
those into the admin console yields /v1/logs/v1/logs and a 404 the exporter
reports as a delivery failure. Claude Code and Cowork send logs; the office
agents send traces; all three take the same base.

  dashboard        https://{{ default .Values.ingress.host .Values.ingress.dashboard.host }}/
{{- else if .Values.dashboard.enabled }}
  dashboard        not routed (ingress.dashboard.enabled is false):
                   kubectl port-forward svc/{{ include "forgd-verdict.fullname" . }}-dashboard 8080:{{ .Values.dashboard.port }}
{{- end }}
{{- if .Values.connector.enabled }}
  Claude connector {{ include "forgd-verdict.connectorResource" . }}

The connector URL goes into Claude as a custom connector, with OAuth against
your identity provider (docs/CONNECTOR.md). Anything Claude reads through it
enters your Claude conversations, where the Compliance API retains it and
the inference hook scans it.
{{- end }}
{{ if .Values.ingress.diagnostics.enabled }}
  health           https://{{ .Values.ingress.host }}/healthz    (verdict)
                   https://{{ .Values.ingress.host }}/health     (collector)
{{ if and .Values.dashboard.enabled .Values.ingress.dashboard.enabled (not .Values.ingress.dashboard.host) }}
The dashboard shares the public hostname, so its /healthz is not reachable:
that path belongs to the verdict server and /health to the collector. Set
ingress.dashboard.host to give it a name of its own -- that also lifts the
refusal on server-scoped annotations and gives it its own certificate.
{{ end -}}
{{ end -}}
{{- else -}}
No ingress. Port-forward to reach a role:

  kubectl port-forward svc/{{ include "forgd-verdict.fullname" . }}-verdict 8000:{{ .Values.verdict.port }}
{{ end }}
Check the roll landed, rather than assuming it:

  kubectl rollout status deploy/{{ include "forgd-verdict.fullname" . }}-verdict
